Earnings Surprise Alpha Strategy

This project replicates a simplified version of the research workflow used by event-driven hedge funds and quantitative equity managers to study the impact of earnings announcements on stock returns.

The strategy is based on the hypothesis that stocks experiencing significant positive earnings surprises continue to outperform after the announcement, while stocks with negative surprises continue to underperform—a phenomenon known as Post-Earnings Announcement Drift (PEAD).

The research pipeline includes:

Earnings data collection and validation
Feature engineering and surprise scoring
Event study analysis
Abnormal Return (AR) estimation
Cumulative Abnormal Return (CAR) analysis
Statistical hypothesis testing
Long/short signal generation
Portfolio backtesting
Risk and performance analytics
Interactive visualization dashboard
